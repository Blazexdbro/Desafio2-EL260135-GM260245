Descripción del proyecto
Este proyecto es el Desafío 2 de la asignatura Programación de Algoritmos (PAL404). Consiste en dos ejercicios desarrollados en C# como aplicación de consola.
El ejercicio 1 es el juego del ahorcado, donde el programa selecciona una palabra al azar de un banco de 10 palabras y el jugador debe adivinarla letra por letra con un máximo de 6 intentos fallidos.
El ejercicio 2 es un sistema de registro de notas estudiantiles, donde se ingresan nombres y notas de N estudiantes, se calculan promedios, nota máxima y mínima, y se genera un reporte con la letra y estado de cada estudiante.


Para poder utilizarlo, clonar el repositorio con el siguiente comando:

git clone https://github.com/Blazexdbro/Desafio2-EL260135-GM260245

Luego abrir la carpeta en VSCode y en la terminal colocar el siguiente comando dentro de la carpeta que contiene el .csproj:

dotnet build

le generara una carpeta en modo debug del programa con su respectivo .exe
